# Sasi's Portfolio

Welcome to Sasi's Portfolio! This repository contains the source code for the portfolio project.

## Folder Structure

- `client/`: Contains the frontend web application built with React, Vite, and Three.js.

## Getting Started

### Prerequisites
- Node.js
- npm or yarn

### Setup

1. Navigate to the client directory:
   ```bash
   cd client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Copy `.env.example` to a new file named `.env.local` and provide the required values (e.g., `GEMINI_API_KEY`).
   ```bash
   cp .env.example .env.local
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

The application will be running locally.
